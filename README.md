# VICTORA React Portfolio

Landing page React + Vite berdasarkan referensi desain yang diberikan.

## Jalankan

```bash
npm install
npm run dev
```

Buka URL Vite yang muncul di terminal.

## Build production

```bash
npm run build
npm run preview
```

## Struktur

- `src/main.jsx` — komponen dan data tim/portfolio
- `src/styles.css` — styling responsive
- `public/assets/` — aset gambar hasil crop dari referensi
